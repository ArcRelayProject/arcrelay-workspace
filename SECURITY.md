# Security policy

Security fixes are provided for the current `main` branch and the latest
published desktop release.

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting feature on the relevant ArcRelay repository. Include the affected
version or commit, impact, reproduction steps, and any suggested mitigation.
Do not open a public issue for an undisclosed vulnerability.

The maintainers will acknowledge a complete report, investigate it, and
coordinate disclosure after a fix is available. Reports concerning the
proprietary mobile application or private services should be filed against this
integration repository through the same private channel.
